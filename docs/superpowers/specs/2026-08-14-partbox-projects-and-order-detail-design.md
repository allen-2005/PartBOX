# PartBOX 项目管理与订单详情导入设计

## 1. 目标

在保留当前浅色蓝灰、高信息密度库存主界面的基础上，完成十项统一升级：优化品牌、筛选栏与统计栏；将右侧元件概览改为固定宽度可折叠窗格；支持点击复制信息；新增项目管理、元件勾选及项目库存差额同步；同时支持“物料明细对账单”和“订单详情”两种立创商城 Excel。

## 2. 方案选择

### 方案 A：项目仅保存清单，导出时直接按当前数量全量扣减

实现简单，但重复点击会重复扣库存，修改用量后也无法可靠退回，不采用。

### 方案 B：项目保存“当前用量”和“已同步用量”，按差额同步（采用）

每个项目元件同时记录当前项目用量与上次已导出的用量。导出时只把差额写入库存：用量增加生成项目出库，用量减少生成项目退回；差额为零不产生流水。这样可重复点击、不重复扣减，并能完整审计。

### 方案 C：项目拥有独立虚拟库存仓库

功能最强，但会引入采购分配、退料、跨项目调拨等超出本轮目标的概念，不采用。

## 3. 主界面

- Logo：英文 `PartBOX` 与中文“小料仓”占用完全相同的固定宽度；中文三个字使用原字体放大并均匀分布，使首尾与英文视觉左右对齐。
- 顶栏删除“清除筛选”。保留搜索框，右侧依次为“＋ 导入物料明细”和“＋ 导入订单详情”。
- 分类筛选区上下留白一致，按钮在筛选区域内垂直居中。
- 统计卡顺序改为：订单数、元件种类、库存总数、累计采购。卡片压缩高度，标题在左、醒目的数值在右。
- 库存表增加最左侧勾选列。未选中为蓝色描边方框，选中为蓝底白色对号；支持多行勾选，表头提供全选／取消全选。
- 保留现有列拖动、隐藏和排序持久化。勾选列固定在最左侧，不参与用户列布局持久化。
- 右侧元件概览固定宽度，不可拖拽调整。表格和概览之间放置窄型折叠按钮，可随时隐藏／显示概览；折叠状态跨重启保存。
- 右侧商品编号、类别、封装、品牌、库存、最近购买和位置／备注的值均可单击复制。复制后显示短暂提示，空值不复制。

## 4. 我的项目

- 左侧“元件库存”下面新增“我的项目”。进入后显示项目列表、新建／重命名／删除项目操作和当前项目元件表。
- 在库存页勾选元件后点击“导入到项目”，选择目标项目即可批量加入；已存在于项目中的元件不会重复创建。
- 项目表使用淡黄色背景，与库存页浅蓝色区分。
- 项目表显示：商品编号、商品类型、商品名称、商品型号、封装格式、品牌、项目用量。前六列只读，“项目用量”可编辑且必须是非负整数。
- “导出变更到元件库存”按 `项目用量 - 已同步用量` 计算差额：正差额减少库存，负差额退回库存，零差额跳过。整个项目的同步在单个数据库事务中执行，任一元件库存不足则整批不变。
- 每个差额写入标准库存流水，类型分别为 `project_out` 和 `project_return`，备注包含项目名称；同时写入项目操作记录，保存项目、元件、变化前后用量、库存变化和时间。
- 项目页面提供操作记录表，能查看每次同步结果。删除项目只允许在所有项目元件“当前用量等于已同步用量”时执行，避免已扣库存失去归属。

## 5. 两种订单导入

- “导入物料明细”沿用现有多文件导入和字段映射。
- “导入订单详情”使用独立入口和解析器，识别“订单编号”“下单日期”及“商品明细列表”表头。
- 订单详情字段映射：商品编号→商品编号，品牌→品牌，厂家型号→商品型号，封装→封装格式，商品名称→商品名称，订购数量（修改后）→订购数量，商品单价→含税单价，商品金额→小计金额。
- 商品类型由现有分类规则根据商品名称、型号和封装推断；商品单位和数量从“20个”“1台”等文本中拆分。货币文本去除 `￥`、千位分隔符和 `/个` 等单位后转换为数值。
- 每份订单详情只读取真实有数据的主工作表，忽略模板空表。重复检测继续使用文件 SHA-256 和订单行指纹，避免两种导入格式重复计入同一采购行。
- 导入预览和入库决策沿用现有规则；两个入口分别限制并解释期望格式，读错文件时给出清晰中文提示。

## 6. 数据结构与迁移

新增表：

- `projects`：项目名称、创建时间、更新时间。
- `project_components`：项目、元件、当前项目用量、已同步用量，项目与元件唯一。
- `project_operations`：项目同步操作的批次摘要。
- `project_operation_lines`：每个元件的用量差额、库存变化及关联库存流水。

数据库初始化使用 `CREATE TABLE IF NOT EXISTS` 增量迁移，现有元件、采购、库存流水和用户设置不受影响。

## 7. 错误处理

- 项目名不能为空且不可重复。
- 项目用量只接受非负整数。
- 差额出库遵循现有“是否允许负库存”设置；不允许负库存时，整批同步前先校验并一次性提示库存不足元件。
- 订单详情缺少关键表头、订单号或有效商品行时，阻止导入并显示具体原因。
- 数据库写入和项目同步失败时回滚整个事务。

- 单元测试覆盖订单详情两份样本的字段、数量、金额、单位、订单号和重复指纹。

- UI 测试覆盖 Logo 对齐、筛选间距、统计顺序、两个导入按钮、清除筛选移除、勾选列、项目导航、右栏固定折叠及点击复制。
- 完整测试通过后重新生成 EXE，执行无数据与现有数据库启动烟雾测试，再替换桌面 `PartBOX` 文件夹中的程序、源码、UI 和使用说明，保持桌面快捷方式可用。
