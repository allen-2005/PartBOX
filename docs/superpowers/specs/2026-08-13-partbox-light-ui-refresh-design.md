# PartBOX 浅色界面改版设计

## 1. 目标

在不改变订单导入、库存流水和本地数据库结构的前提下，提高主界面信息密度、整洁度与一致性。界面只使用白色、浅灰蓝、品牌蓝和深灰文字，不加入装饰性强的多色元素。

本规格覆盖原设计规格第 8～10 节中与主界面样式、分类按钮和可编辑字段冲突的内容。

## 2. 顶栏

- 顶栏改为浅色背景，不再使用深蓝底或白色品牌底块。
- 左侧字标分两行：上行为 `PartBOX`，下行为 `小料仓`。
- 两行均使用蓝色、无衬线粗体；上行字号更大，下行字距略增。
- 两行文字使用相同左右边界，形成左对齐且视觉等宽的简约字标。
- 搜索框占用顶栏主要剩余宽度，窗口缩放时优先伸缩；不再限制为 480 像素。
- 清除筛选和导入按钮保持在右侧，按钮使用同一圆角和高度。

## 3. 动态分类

- 分类快捷按钮来自当前数据库中实际存在的元件，而非固定写死。
- 分类依据为每个元件的 `商品类型＋商品名称`，按关键词归并为常用大类，例如电阻、电容、芯片、三极管、二极管、连接器、开关、继电器、电感、LED、传感器和其他。
- 同一元件只归入一个优先级最高的大类，避免重复计数。
- 某类没有元件时不显示该按钮；例如只导入电阻时，只显示“全部”和“电阻”。
- “全部”始终显示；“库存不足”和“库存为零”是库存状态筛选，始终保留。
- 点击分类按钮继续复用现有跨字段搜索；分类与搜索词同时生效。
- 动态分类只影响界面筛选，不修改立创导入的原始“商品类型”字段。

## 4. 统计卡片与主体布局

- 四个统计卡片横向等宽铺开，不在右侧留下大块空白。
- 卡片使用浅蓝灰填充、细边框、统一圆角；数值与标题不再各自放置白色小底块。
- 表格区域继续保持高信息密度和横向滚动。
- 左侧导航、中央内容和右侧概览采用同一浅色卡片语言：浅底、细边框、适度留白。
- 左右侧栏宽度略增加；右侧概览字段间距一致，操作按钮横向充分利用可用宽度。

## 5. 表格编辑规则

- 只有“当前库存”和“备注”两列可直接编辑。
- 商品编号、商品类型、商品名称、商品型号、封装格式、品牌、累计购买、商品单位、价格、采购金额、时间、存放位置和更新时间全部只读。
- 不再使用整片浅黄色表示可编辑区域。
- “当前库存”和“备注”通过极浅蓝底或轻量提示区分，且不影响整表阅读。
- 修改当前库存仍生成库存校准流水；修改备注立即保存。

## 6. 滚动条与统一样式

- 横向和纵向滚动条使用相同的浅灰轨道、灰蓝滑块和小圆角。
- 滚动条宽度控制在 10～12 像素；滑块悬停时略加深。
- 隐藏突兀的黑色箭头按钮和网纹区域，不使用阴影、渐变或高饱和装饰。
- 表头、输入框、按钮、选中行、侧栏和卡片统一使用同一套蓝灰色阶。

## 7. 实现边界

- 动态分类逻辑放在独立纯函数中，便于测试关键词优先级和空分类行为。
- 主窗口每次刷新数据后重建分类按钮，但保留仍然有效的当前分类选择；分类消失时回到“全部”。
- 数据查询仍通过现有 `InventoryService.list_components` 完成，动态大类在界面层对结果做确定性筛选，不修改数据库表结构。
- 辅助页面沿用全局样式表，因此滚动条、表格、输入框和按钮会同步统一。

## 8. 验收标准

- 只有电阻数据时，不出现电容、芯片或三极管按钮。
- 混合订单导入后，仅出现实际命中的大类。
- 搜索、分类、库存不足和库存为零筛选仍正常组合使用。
- 主表除“当前库存”和“备注”外无法编辑。
- 统计卡片等宽占满中间区域，搜索框明显加宽。
- 顶部显示蓝色两行 `PartBOX`／`小料仓` 字标，无白底块。
- 左右侧栏、表格和滚动条风格统一、浅色、克制。
- 原订单数据、库存流水、导入与备份功能行为不变。
