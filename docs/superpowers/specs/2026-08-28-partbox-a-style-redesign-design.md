# PartBOX A 风格全界面改造设计

## 目标

将用户选定的 A 方案“柔和工作台”应用到 PartBOX 全部桌面界面。新版以冷白公共框架配合分页面柔和色调，保持高密度数据扫描效率，同时减少长时间使用时的视觉疲劳，并让用户仅凭底色即可辨认当前工作区。

本次只改视觉系统、布局节奏和状态表达，不改数据库结构、业务规则、字段内容或既有操作语义。

## 设计方向

- **模式：** Operate。界面服务于频繁搜索、排序、多选、编辑和库存操作。
- **视觉关键词：** 柔和、清楚、专业、安静、高密度。
- **设计参数：** 视觉变化 3／10，动效 2／10，信息密度 8／10。
- **主题：** 只提供浅色主题。顶栏、导航和通用控件保持统一，各业务页面使用不同的柔和浅色作为识别色。
- **品牌：** 保留现有 PartBOX 与“小料仓”艺术字图片，不换成普通字体，不重绘 Logo。
- **图标：** 使用 Qt 原生标准图标或项目现有同一套图标，不使用表情符号。

## 色彩系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 应用背景 | `#F6F8FB` | 主窗口公共底色 |
| 顶栏与侧栏 | `#FBFCFE`／`#F8FAFD` | 一级结构 |
| 内容表面 | `#FFFFFF` | 表格、输入框、主要内容区 |
| 柔和表面 | `#EDF2F7` | 表头、次级区域 |
| 主文字 | `#193857` | 标题和关键数据 |
| 正文 | `#293C51` | 表格与正文 |
| 次文字 | `#718197` | 描述、标签和禁用信息 |
| 边框 | `#D7E1EB`／`#DCE4EE` | 控件、分区和表格线 |
| 品牌蓝 | `#4D78CF` | 主按钮、焦点、选中状态 |
| 品牌蓝浅底 | `#E7EEFB`／`#EAF1FD` | 导航、筛选和行选中 |
| 项目淡黄 | `#FFF5D7` | “导入到项目”等项目动作 |
| 项目文字／边框 | `#76530B`／`#E5CA7B` | 项目动作状态 |

公共框架只使用品牌蓝作为常规交互强调色。业务页面的浅色底只负责区分工作区，不改变按钮、焦点和危险操作的语义；红色只表达删除、错误和不可逆操作。

## 页面识别色

| 页面 | 主背景 | 次级表面／选中底 | 页面角色 |
| --- | --- | --- | --- |
| 元件库存 | `#EEF5FF` | `#E3EEFC` | 淡蓝，清晰、稳定，作为默认主页面 |
| 物料对比 | `#FFF8E6` | `#F8EDC8` | 淡黄，突出差异与比对关系 |
| 我的项目 | `#EFF9F0` | `#DFF1E2` | 浅绿，表达已组织、已保存的项目配置 |
| 库存流水 | `#F4F1FB` | `#E9E2F5` | 淡紫灰，表达历史变化与时间记录 |
| 导入记录 | `#FFF3EC` | `#F8E5D8` | 淡杏色，表达外部数据进入系统 |
| 设置 | `#F2F5F7` | `#E6EBEF` | 浅灰蓝，保持安静并弱化低频操作 |

每个页面的表格外框、空状态和次级区域可以使用该页面的色系，但正文表格单元格仍以接近白色的表面为主，避免大面积彩色降低可读性。BOM 库存计算从“我的项目”进入，因此沿用项目页浅绿色，并用淡黄色单独标识需要用户判断的补货信息。

## 字体、形状与间距

- 中文使用 `Microsoft YaHei UI`，回退到 `Noto Sans SC` 和 `Segoe UI`。
- 正文默认 13px；表格 13px；辅助文字 12px；页面标题 20px；关键统计值 22-24px。
- 数量、价格和日期启用等宽数字显示，保持列内对齐。
- 卡片使用 10px 圆角；按钮、输入框、筛选和表格外框使用 8px；行内编辑器使用 5px。
- 阴影只用于窗口级浮层和弹窗，普通内容主要依靠背景层级和 1px 边框区分。
- 间距采用 4、6、8、10、12、16、20、24px 序列，避免同一层级出现无规则间距。

## 主窗口结构

### 顶栏

- 高度约 88px，左右留白 20-24px。
- 左侧艺术字 Logo 区宽约 180px，英文与中文图片等宽展示；使用平滑缩放并保持原始纵横比，避免模糊和拉伸。
- 搜索框高度 46-48px，与 Logo 保持 20px 左右间距。
- “导入物料明细”为唯一顶栏主按钮，保持单行并提供明确悬停、按下、禁用和键盘焦点状态。

### 左侧导航

- 展开宽度维持约 168px，背景为极浅雾蓝。
- 每项高度 40-42px，左右内边距一致。
- 当前页面使用浅蓝底、品牌蓝文字和清晰字重，不增加装饰性圆点或编号。
- 导航顺序和文字保持：元件库存、物料对比、我的项目、库存流水、导入记录、设置。

### 内容区

- 页面外边距统一为 16px；标题、筛选、统计、表格之间使用 10-12px 垂直间距。
- 页面标题左对齐；页面主要操作固定在标题区右侧，避免散落在统计卡或表格空白处。
- 四张统计卡尺寸一致，信息顺序保持订单数、元件种类、库存总数、累计采购；卡片缩短横向留白并适度增加高度。
- “导入到项目”保持与统计卡同一水平区域的淡黄色动作块，语义和其他蓝色主操作区分。

## 数据表格

- 全部业务表格共用同一视觉基础：白底、浅灰蓝表头、36px 默认行高、1px 网格线、偶数行极浅色差。
- 排序小三角、复选框、Shift 范围选择、行身份绑定、列宽持久化和横向滚动行为不变。
- 选中行使用当前页面的次级识别色，并在最左侧增加 2px 品牌蓝标识；编辑焦点统一使用 1px 清晰蓝框，避免粗重边框。
- 键盘焦点必须完整可见；表格编辑器、位号输入、数量步进器和行删除按钮均可通过现有键盘路径操作。
- 项目表格改用浅绿色语义；淡黄色仅保留给“导入到项目”和需要用户判断的补货信息。
- 危险操作只在悬停、按下和确认对话框中出现红色，不把整列长期染红。

## 各页面规则

### 元件库存

- 沿用 A Demo 的标题、筛选、四项统计、主表和右侧摘要结构。
- 页面采用淡蓝色调，以 `#EEF5FF` 为底、`#E3EEFC` 为次级表面；表格正文保持近白色。
- 分类筛选使用白底描边，当前分类使用浅蓝底。
- 右侧元件摘要继续可折叠；空状态、字段标签和操作按钮改用统一层级。

### 物料对比

- 页面仍为无限数量横向对比，不设置上限。
- 页面采用淡黄色调，以 `#FFF8E6` 为底、`#F8EDC8` 为差异填充。
- 所有普通单元格使用一致的浅黄白基底；内容不同的单元格使用稍深但同色系的填充。
- 价格曲线、空状态、移除和清空操作纳入统一按钮与边框系统。

### 我的项目

- 页面采用浅绿色调，以 `#EFF9F0` 为底、`#DFF1E2` 为选中和次级表面。
- 项目列表保留折叠、右键重命名／删除和底部新建项目。
- 项目合计、保存元件配置、导出变更到元件库存、位号编辑、数量步进器、逐行垃圾桶删除和操作记录行为全部保留。
- “保存元件配置”仅保存项目页面配置；“导出变更到元件库存”才写入库存，视觉层级继续明确区分。

### 库存流水、导入记录和设置

- 库存流水使用淡紫灰，导入记录使用淡杏色，设置使用浅灰蓝；三页与前三个主业务页面均可仅凭背景色区分。
- 移除页面内零散的硬编码字号和样式，统一使用页面标题、工具栏、表格和危险操作令牌。
- 设置页的数据重建等危险操作与普通备份、导出操作分组，使用红色文字或描边但不使用大面积红底。

### BOM 库存计算

- 三步流程、候选匹配、归零提醒、额外补货数量、撤销／上一步／下一步和立创商城 BOM 导出逻辑不变。
- 步骤信息、候选面板和提醒信息改用 A 风格的浅色分层；黄色只用于需要用户决策的补货和项目语义。

### 弹窗

- 导入预览、入库／出库、确认删除和错误提示统一到白底、雾蓝边框、8-10px 圆角体系。
- 主按钮位于右侧，取消在其左侧；危险确认使用红色主操作，并保留明确的二次确认文案。

## 状态与动效

- 只使用悬停、按下、焦点、展开／收起的短促反馈，不加入页面入场动画或装饰动画。
- 悬停状态只改变背景或边框；按下状态允许 1px 视觉位移。
- 加载、空数据、失败、禁用和已保存状态必须有文字或形状辅助，不只依赖颜色。

## 实施边界

- 主要改动集中在 `src/partbox/ui/theme.py`、`src/partbox/ui/forms/main_window.ui` 及各页面中现存的局部硬编码样式。
- 保持所有由 Python 绑定的 `objectName`，不改变控件信号、数据库调用、排序键、选择集合或保存时机。
- 保留外部 `main_window.ui` 的可编辑与回退机制。
- 不引入新的前端框架、网络依赖或在线字体。
- 用户工作区当前已有大量未提交修改；实施时只提交本次明确涉及的文件，不覆盖或回退其他修改。

## 验证

1. 先运行现有全量测试，建立当前基线。
2. 为主题令牌和关键对象名补充必要的界面测试。
3. 完成后运行全量测试，确保排序、Shift 多选、行身份、位号键盘移动、数量步进、项目保存、逐行删除、物料对比和 BOM 计算没有回归。
4. 使用现有渲染脚本分别截取主库存页、物料对比、我的项目、BOM 向导和核心弹窗。
5. 在 1440×820 和最小 1050×650 两种窗口尺寸检查：无控件遮挡、表头与行对齐、滚动条可用、按钮不换行、焦点可见。
6. 视觉检查最多两轮：首轮集中修复，第二轮确认，不进行无止境微调。

## 验收标准

- 用户一眼可识别为已选定的 A 风格，而不是旧界面的轻微换色。
- 所有页面共用同一套字体、间距、圆角、控件和状态规则，同时准确使用各自的柔和页面识别色。
- 元件库存为淡蓝、物料对比为淡黄、我的项目为浅绿；库存流水、导入记录和设置也分别使用淡紫灰、淡杏色和浅灰蓝，页面之间不重复。
- Logo 清晰、比例正确，顶栏和左侧导航留白舒适。
- 数据表格保持紧凑、清晰、可长时间阅读。
- 用户之前明确要求的所有交互和数据语义保持不变。
- 自动化测试通过，关键页面截图无错位、截断或低对比状态。
