# PartBOX 表格功能保留与界面回退设计

## 目标

界面完整恢复到版本 `07bbc7e` 的布局与操作方式，仅保留本轮新增的元件表格列功能。回退只涉及程序代码和界面设置，不修改订单、元件、库存或流水数据库。

## 保留

- 表头可拖动调整列顺序。
- 列宽可拖动调整。
- 右键表头以复选菜单隐藏或显示列。
- 提供“全部显示”和“恢复默认列布局”。
- 至少保留一列显示。
- 表头右侧显示简洁、对齐的 `▲/▼` 排序图标。
- 列顺序、列宽、隐藏状态、排序字段及方向关闭软件后保持。
- 数量、库存和金额按数值排序，不按文本排序。
- 表头配置损坏或与新版本列定义不兼容时安全恢复默认。

## 回退

- 删除搜索栏下方的浏览器式标签栏。
- 左侧导航恢复为：元件库存、库存流水、导入记录、设置；点击后直接切换页面。
- 删除完整入库／出库页面，右侧“入库”“出库”恢复打开精致弹窗。
- 统计卡恢复为：元件种类、库存总数、累计采购、订单数。
- Logo 恢复 `07bbc7e` 的字体、字号和间距。
- 删除仅为多标签页和完整入出库页面新增的会话设置与测试代码。

## 验收

- 主界面视觉与 `07bbc7e` 一致，不显示浏览器标签栏。
- 表格列功能完整可用且重启后恢复。
- 入库／出库继续使用上一版弹窗。
- 原有导入预览、滚动条、搜索、筛选和库存数据行为不变。
- 完整自动化测试、视觉截图和桌面 EXE 启动验证通过。
