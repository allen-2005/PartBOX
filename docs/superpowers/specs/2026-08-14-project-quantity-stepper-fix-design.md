# 项目用量计数器修复设计

## 问题

原生 `QSpinBox` 同时受全局输入框最小高度、表格行高和表格选择行为控制。在高 DPI 下，控件绘制区域超过单元格，出现行错位；点击原生子控件还会把事件传给表格，导致行被选中，交互不稳定。

## 设计

用专用 `ProjectQuantityStepper` 替换表格中的原生 `QSpinBox`。控件由只读数量标签和两个独立按钮组成，按钮直接发出数量变化，不依赖表格选择、焦点或编辑模式。控件固定高度 32px，表格行固定 36px，单元格四周保留 2px 空白。

上箭头数量加 1；下箭头数量减 1但最低为 1。变化继续调用现有 `ProjectService.set_quantity`，并实时更新小计和项目合计。排序后控件仍通过 component ID 绑定正确元件。

## 验收

- 未选中任何行时，第一次点击上箭头即可把 1 改为 2。
- 点击上下箭头后，表格仍没有选中行。
- 下箭头不能把数量减到 0。
- 计数器高度不超过 32px，所有项目表行高严格为 36px。
- 排序后点击计数器只修改其所在元件。
