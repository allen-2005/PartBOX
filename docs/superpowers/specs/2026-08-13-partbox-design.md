# 小料仓 PartBOX 设计规格

## 1. 目标与范围

小料仓 PartBOX 是面向电子工程学生的 Windows 本地电子元件库存管理器。用户导入立创商城物料明细对账单后，可在一个高信息密度表格中查询元件、查看采购情况、维护实际库存，并记录所有库存变动。

首版仅管理本机单用户数据，不包含账号、云同步、联网抓单或多人协作。用户提供的三个 `.xls` 文件仅用于验证格式兼容性和测试导入器；交付数据库为空，程序和安装包不内置这些订单或测试统计。

## 2. 产品名称与交付

- 中文名：小料仓
- 英文名：PartBOX
- 窗口标题：小料仓 PartBOX
- 副标题：电子元件库存管理器
- 可执行文件：`PartBOX.exe`
- 最终交付目录：`C:\Users\lenovo\Desktop\小料仓PartBOX`
- 正常使用不要求用户安装 Python。

## 3. 技术架构

- Python 3.10 或更新版本。
- PySide6 构建 Windows 桌面界面。
- SQLite 保存本地业务数据。
- pandas、xlrd、openpyxl 分别完成数据整理及 `.xls`、`.xlsx` 读取。
- PyInstaller 生成 Windows 可执行程序。
- 界面、应用服务、数据库访问、导入解析相互分离，便于独立测试和后续修改。

## 4. 真实立创文件格式

立创物料明细对账单包含一个物料明细工作表和一个“发票汇总清单”工作表。物料明细表第 2 行是表头，共 25 列：

订单编号、订单状态、下单时间、收货人、客户料号、商品编号、品牌、商品类型、商品名称、商品型号、封装格式、订购数量、商品单位、单价（人民币含税）、小计金额（人民币含税）、发货日期、快递公司、快递单号、签收日期、发票号、开票时间、客户代表、归属原订单、bom标识、订单合同编号。

导入器不得依赖固定工作表名称或固定第 2 行，而应扫描前 20 行寻找包含“订单编号”“商品编号”“商品名称”“订购数量”的表头行。商品编号为空且商品名称为“价外费用（配送费）”的行作为费用记录保存，不创建元件。汇总、说明、全空行及其他非商品行跳过并在导入预览中计数。

## 5. 数据模型

### 5.1 元件

每种元件在主表仅一行。保存商品编号、品牌、商品类型、商品名称、商品型号、封装格式、商品单位、当前库存、累计购买数量、累计采购金额、最近单价、最近下单时间、存放位置、备注、停用状态和最后修改时间。

用户可修改导入后的商品资料、库存、存放位置和备注；立创原始订单行不随这些修改而变化。

### 5.2 采购记录

每条有效商品明细保留全部 25 个原始字段、来源文件标识、导入批次、规范化明细指纹和关联元件。不同订单购买同一元件时保留各自价格和时间，并在元件主表累计数量与金额。

### 5.3 库存流水

每次订单入库、手工入库、手工出库、库存校准和撤销操作均记录：元件、操作类型、变化数量、操作前库存、操作后库存、时间、备注、来源采购记录和被撤销关系。撤销通过新增反向流水实现，不删除历史。

### 5.4 导入批次与费用

导入批次保存文件名、文件 SHA-256、导入时间、结果统计和是否强制导入。配送费等费用行单独保存，用于采购统计，但不参与元件种类和库存总数。

## 6. 元件匹配与去重

同一元件的匹配顺序：

1. 商品编号非空时，以规范化商品编号精确匹配。
2. 商品编号为空时，以规范化后的“商品型号＋封装格式”精确匹配。
3. 仍无法确定时进入人工确认列表，用户选择合并或创建新元件。

重复导入采用两层判断：

1. 文件 SHA-256 完全相同，默认拦截整个文件。
2. 文件不同但订单明细指纹相同，默认跳过重复明细。指纹由订单编号、商品编号、订购数量、小计金额和下单时间组成。

用户可以选择强制导入；程序必须再次确认并清楚提示可能造成采购数量和库存重复。强制导入仍保留批次标识以便审计。

## 7. 导入流程

1. 用户选择一个或多个 `.xls` 或 `.xlsx` 文件。
2. 程序解析文件并显示预览：有效商品、新元件、已存在元件、重复明细、费用行和异常行。
3. 首次空库导入时，新元件当前库存默认等于本次购买数量。
4. 后续导入的新元件也默认以购买数量创建库存。
5. 已存在元件不会自动增加库存；程序提供逐项选择及“全部加入／全部不加入”，用户确认后才增加库存并生成订单入库流水。
6. 用户确认后，导入批次、采购记录、元件汇总和库存流水在一个 SQLite 事务中写入。任一错误使整个批次回滚。
7. 导入成功前自动创建数据库备份。

## 8. 主界面

界面采用用户确认的第三版草图。

- 顶部：应用名、跨字段搜索框、清除筛选和“导入立创订单”按钮。
- 左栏：元件库存、入库／出库、库存流水、导入记录、设置。保持简洁，不显示二级说明。
- 中间顶部：全部、电阻、电容、芯片、三极管、库存不足、库存为零等快速筛选。
- 统计卡片：元件种类、库存总数、累计采购金额、订单数。空库全部显示 0。
- 中间主体：高信息密度元件表，支持横向滚动、纵向滚动、拖动列宽、调整列顺序和排序。
- 右栏：当前选中元件的商品编号、类别、封装、品牌、库存、最近购买、位置和备注，并提供入库、出库和查看库存流水按钮。

主表默认列为：商品编号、商品类型、商品名称、商品型号、封装格式、品牌、当前库存、累计购买、商品单位、最近单价（含税）、累计采购金额、最近下单时间、存放位置、备注和最后修改时间。所有这些信息无需打开详情页即可查看；右栏只作为快速概览，不是查看完整信息的必经步骤。

## 9. 搜索与筛选

搜索框对商品编号、品牌、商品类型、商品名称、商品型号、封装格式、存放位置和备注做不区分大小写的包含匹配。输入“电阻”“电容”“三极管”“0603”“CLCC”“LM358”等均可命中相关记录。

搜索词以空格分隔时采用 AND 语义，例如“电阻 0603”只显示所有可搜索字段合并文本中同时包含两个词的元件。分类按钮与搜索条件同时生效。清除筛选恢复全部元件。

## 10. 编辑和库存操作

- 商品资料、当前库存、存放位置和备注均允许修改。
- 直接修改当前库存生成“库存校准”流水，记录修改前后值。
- 入库／出库操作要求数量为正整数，并可填写用途或备注。
- 默认禁止出库后库存小于 0；设置中可开启允许负库存。
- 删除元件前二次确认，首选“停用”而非物理删除。存在采购或流水记录的元件不得物理删除。
- 错误库存操作可撤销；撤销创建反向流水并恢复库存。

## 11. 辅助页面

- 入库／出库：搜索并选择元件，录入数量、备注和操作时间，预览库存变化后确认。
- 库存流水：按元件、类型和日期筛选，显示操作前后库存和备注，并支持撤销合法操作。
- 采购记录：显示每次购买的完整原始字段，可按订单或元件筛选。
- 导入记录：显示批次、来源文件、结果统计、重复／强制状态和错误摘要。
- 设置：负库存开关、低库存阈值、数据库位置、手动备份、恢复、导出库存表和重建空数据库。

## 12. 数据安全与错误处理

- 数据库默认存放在用户可写的本地应用数据目录，不与 `PartBOX.exe` 放在同一目录，避免升级覆盖。
- 每次成功导入前自动备份；允许手动备份与恢复。
- 恢复和重建空数据库属于高风险操作，必须二次确认。重建前自动备份现有数据库。
- Excel 缺少必要表头时列出缺失字段，不写入任何数据。
- 无法读取、类型错误或异常行在预览中给出文件、工作表、行号和原因。
- 所有异常转为可读中文提示，同时将技术详情写入本地日志。
- 窗口正常关闭无需额外保存；每次编辑和确认操作立即事务提交。

## 13. 验收标准

- 可导入真实立创 `.xls` 格式以及等价 `.xlsx` 格式。
- 三个用户样例仅作为自动化或人工测试输入；打包前使用全新空数据库验收。
- 配送费、汇总和说明行不会创建元件。
- 重复文件默认拦截，重复明细默认跳过，强制导入需二次确认。
- 已有元件是否增加库存由用户在导入确认页决定。
- 主表可直接查看全部常用列，并稳定横向滚动、排序、编辑和筛选。
- 搜索可正确命中类别、封装和型号等任一可搜索字段。
- 库存及流水在重启后保持一致；导入失败不产生部分数据。
- 空库、错误文件、缺失字段、重复订单和负库存均有清晰提示。
- 最终 `PartBOX.exe` 在没有 Python 环境的 Windows 电脑上可启动并完成核心流程。
