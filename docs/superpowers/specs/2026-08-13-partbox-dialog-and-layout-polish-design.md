# PartBOX 导入、布局与库存弹窗优化设计

## 1. 目标

修复首次导入时确认表为空的问题，删除左栏与主内容之间的无效空白，加大左栏字号，并把入库／出库弹窗升级为与主界面一致的浅色精致样式。业务规则和数据库结构不变。

## 2. 导入确认页

- 表格同时显示本次可导入的新元件和已有元件，不再只显示已有元件。
- 新元件行第一列显示“自动入库”，只读；其购买数量会按现有规则成为初始库存。
- 已有元件行第一列显示复选框，用户决定本次购买数量是否加入当前库存。
- 表格列为：入库方式、商品编号、商品名称、型号、封装、本次数量。
- 新元件使用浅蓝状态标识；已有元件使用可勾选状态。
- 顶部摘要改成紧凑统计区，显示文件、新元件、已有元件、重复、费用和异常数量。
- “全部加入库存／全部不加入”只作用于已有元件；没有已有元件时按钮禁用。
- 重复跳过、费用和异常继续只在摘要统计，不进入元件表。
- 导入提交仍只向服务传递已有元件的库存选择，新元件自动按原逻辑处理。

## 3. 主界面空白与左栏

- 删除左侧导航与主内容之间的外层 `QSplitter`。
- 使用零间距水平布局：168 像素固定导航栏＋自适应主页面。
- 保留元件表与右侧概览之间的内部 `QSplitter`。
- 左侧导航字号从全局 13 像素提高到 15 像素，条目高度同步增加，保持四项导航清晰舒展。

## 4. 入库／出库弹窗

- 顶部显示操作类型小标签和元件名称。
- 当前库存放进浅蓝信息卡，数值突出显示。
- 数量输入框使用单位后缀和较大高度；入库使用品牌蓝强调，出库使用克制的蓝灰强调，不新增高饱和颜色。
- 用途／备注输入框增加占位提示。
- 库存变化使用独立预览卡，显示“变动前 → 变动后”和单位；数量变化时即时刷新。
- 确认按钮使用主按钮样式，取消按钮使用次按钮样式。
- 出库导致负库存时继续使用现有服务校验与中文错误提示。

## 5. 验收标准

- 只有新元件的导入预览会显示全部新元件行，第一列为“自动入库”。
- 新旧混合预览中，只有已有元件产生库存选择结果。
- 左栏与主内容紧邻，不存在额外空白带。
- 左栏导航字号为 15 像素。
- 入库和出库弹窗均显示元件名、当前库存、带单位数量输入、备注、库存变化预览和清晰操作按钮。
- 原有导入提交、库存调整和错误处理行为不变。
