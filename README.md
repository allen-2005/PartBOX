# 小料仓 PartBOX

Windows 本地电子元件库存管理器。支持导入立创商城“物料明细对账单” `.xls`／`.xlsx`，查询元件、维护库存、管理项目用料、记录库存流水，并备份或导出数据。

## 使用

1. 双击 `PartBOX.exe`。
2. 首次启动显示空库。点击右上角“＋ 导入物料明细”，可一次选择多个物料明细对账单。
3. 预览页会列出全部元件，新元件自动建立库存，已有元件可逐项选择是否把本次购买数量加入库存。
4. 在主表搜索类别、封装、型号、品牌等信息；分类按钮按已导入元件自动生成。
5. 主表仅“当前库存”“存放位置”和“备注”可直接编辑；商品类型、名称、型号、封装、品牌和单位按物料明细原文保存，快捷分类只用于筛选。
6. 表头可拖动换序和调宽，右键表头可隐藏／显示列；布局和排序会在重启后恢复。
7. 点击表格每行最左侧的蓝色方框可勾选多个元件；按住 Shift 点击第二行，可连续选择两行之间的全部元件。可将选中元件“导入到项目”，也可“加入对比”。
8. “物料对比”按列展示不限数量的元件，差异字段用稍深的同色背景标出；表格可横向滚动，下方按采购时间显示历史单价曲线。
9. “我的项目”中可以新建项目、Shift 连选并维护“项目用量”和“位号”。单击位号即可输入，编辑时按 ↑／↓ 可保存当前输入并继续编辑相邻行。点击“保存元件配置”只保存该项目的 BOM，不影响库存；点击“导出变更到元件库存”才按与上次同步之间的差额扣减或退回库存。每行最右侧垃圾桶可在确认后直接删除该元件，无需先勾选。左侧项目列表可折叠且会记住状态，重复导出不会重复扣减，库存操作均保留记录。
10. 项目栏底部“导入BOM并计算”可处理立创 EDA 导出的 `.xls`、`.xlsx` 或 `.csv` BOM。先填写制作份数，再核对完全匹配与相似候选；缺料和本次会用光的库存会在导出前集中提示。程序只导出立创商城采购 BOM，随后保存新项目，并由用户决定是否立即将匹配库存出库。
11. 选中一行元件后，使用右侧“入库”或“出库”；右侧信息值可点击复制。边缘箭头可隐藏／显示右栏，状态会在重启后保留。

## 可视化修改界面

`main_window.ui` 仍随程序保留，但“我的项目”等动态页面由程序生成。若不熟悉 Qt Designer，建议直接使用当前界面，不必手动修改。

为了保留按钮和数据功能，请不要删除或修改控件的 `objectName`。如果误删了关键控件，PartBOX 会自动使用 EXE 内置的默认界面；库存数据库不会受影响。桌面 `main_window.ui` 可随时从源码 `src/partbox/ui/forms/main_window.ui` 恢复。

数据默认保存在 `%LOCALAPPDATA%\PartBOX`，不会保存在程序文件夹中。设置页可备份、恢复、导出库存或重建空数据库。

## 开发运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:PYTHONPATH='src'
.\.venv\Scripts\python.exe -m partbox
```
